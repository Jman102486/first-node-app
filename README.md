# secure-task-manager-api

A simple Node.js + Express REST API that allows users to:

- Add tasks
- View all tasks
- Delete tasks

## Tech Stack
- Node.js
- Express
- Nodemon

## Install
npm install

## Run
npm run dev

## API Routes

GET /tasks
POST /tasks
DELETE /tasks/:id

## Example POST body
{
    "text": "My first task"
}
